# Gambar Layanan Kami

Letakkan 4 gambar persegi di folder ini, dengan nama dan urutan berikut:

| File | Kartu |
| --- | --- |
| `gambar1.(jpg\|jpeg\|png\|webp)` | Studio Foto |
| `gambar2.(jpg\|jpeg\|png\|webp)` | Kostum & Baju |
| `gambar3.(jpg\|jpeg\|png\|webp)` | Paket Foto Wedding |
| `gambar4.(jpg\|jpeg\|png\|webp)` | Undangan Digital |

Saran: 600 x 600 px, rasio 1:1, ukuran file <= 200 KB.

Ekstensi dicoba berurutan: jpg -> jpeg -> png -> webp. Cukup pakai salah satu.
Kalau file tidak ada, kartu otomatis menampilkan kotak placeholder.
